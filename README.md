# CV Builder — Редакционный конструктор резюме

Конструктор резюме нового поколения, созданный по принципам редакционного стола (**«Редакция»**) в полном соответствии с **PRD**, **SPEC v1.0** и **DESIGN v1.0**.

Продукт исключает визуальный и смысловой нейрослоп: пользователь выступает автором своего опыта, а ИИ — внимательным редактором, который правит текст на глазах с зачёркиваниями, аккуратными вставками и пометками на полях.

---

## Ключевые особенности

### 1. Концепция «Редакция» и кодекс против нейрослопа
- **Никаких ИИ-клише:** нет искр ✨, летающих роботов, градиентов, стеклянных панелей (`backdrop-filter`) и фиолетовых свечений.
- **Два характерных шрифта:**
  - **Onest** — спокойный, выверенный голос интерфейса и автора;
  - **Comic Relief** — голос редактора (пометки на полях, заголовки разделов, пустые состояния).
  - В итоговых резюме и PDF Comic Relief **не используется** — там работают классические шрифты резюме (Inter, Roboto, PT Serif / PT Sans, Montserrat).
- **Честная работа ИИ:** режим правки текста прямо в документе. Зачёркивание исходных строк (`<del>` в кирпичном цвете `--brick`) → вписывание сильных пунктов достижений (`<ins>` в лазурном цвете `--lazur`) → пометки на полях («перевёл в достижения», «цифры взяты из вашего текста»).
- **Ни одного эмодзи:** заменены строгими иконками Lucide с линией 1.5.

### 2. Шаблоны резюме
- **Modern:** сайдбар 32% (фото, контакты, навыки, языки) + основная колонка на ПК; адаптивная лента с кнопками действий на телефоне.
- **Classic:** 1 колонка, элегантная классическая типографика.
- **Minimal:** сетка 25/75 с заголовками секций слева (стиль Read.cv / Are.na).
- **Creative:** цветная акцентная шапка на всю ширину, 2 колонки, текстовые уровни навыков (без бессмысленных 1–5 шкал-прогрессбаров).
- **ATS:** 1 колонка, чистый структурированный текст без графики и таблиц для автоматических систем скрининга.

### 3. Палитра и контраст
- Базовый акцент: **Самаркандская лазурь** (`#12608A` / `#5FB4D4`).
- 8 предустановленных цветовых схем + свободный выбор цвета.
- Генерация палитры в пространстве **OKLCH** (`culori`) с автоматической коррекцией контраста до стандарта WCAG AA (≥ 4.5:1 к белому фону).

### 4. Экспорт
- **Для компьютера:** PDF, A4.
- **Для телефона:** PDF, 1 непрерывная страница.
- **Картинка:** PNG 1080 px для мессенджеров.
- Анимация сканирующей печатающей головки во время экспорта.
- Транслитерация имени файла по ГОСТ 7.79-2000 Б.

## Структура монорепозитория

```
cv-builder/
├── apps/
│   ├── web/                    # React 19 SPA (Vite 6, Tailwind 4, Zustand, Motion)
│   │   ├── src/
│   │   │   ├── pages/          # Home (разворот лендинга), Editor (редакционный стол), Render
│   │   │   ├── features/       # wizard, ai (EditorialMode), design, export (ExportModal)
│   │   │   ├── store/          # resume.ts (Zustand с автосохранением и офлайн-кэшем)
│   │   │   └── styles/         # tokens.css, desk.css
│   └── api/                    # Fastify 5 REST + SSE сервер
│       └── src/
│           ├── db/             # Drizzle PostgreSQL schema + хранилище
│           ├── modules/        # resumes, ai (SSE streaming), photos, export, auth
│           └── server.ts
├── packages/
│   ├── shared/                 # Zod-схемы ResumeData, translit, typograf, словари
│   ├── templates/              # Шаблоны (Modern, Classic, Minimal, Creative, ATS), темы, палитры
│   └── ai-prompts/             # Промпты, защита от галлюцинаций, анти-слоп валидация
├── docker/
│   ├── docker-compose.yml      # Nginx, API, Worker, Postgres, Redis, MinIO
│   └── nginx.conf
└── scripts/
    └── copy-lint.ts            # CI-скрипт контроля текстов против слопа и эмодзи
```

## Запуск проекта

### 1. Установка зависимостей
```bash
pnpm install
```

### 2. Запуск в режиме разработки
```bash
# Запуск фронтенда (порт 3000) и бэкенда (порт 3001) параллельно:
pnpm dev
```
- Веб-приложение доступно по адресу: [http://localhost:3000](http://localhost:3000)
- API сервер доступен по адресу: [http://localhost:3001](http://localhost:3001)

### 3. Прогон тестов (Vitest)
```bash
pnpm test
```

### 4. Проверка текстов на анти-слоп (Copy-Lint)
```bash
pnpm lint:copy
```

### 5. Сборка для продакшна
```bash
pnpm build
```

### 6. Запуск через Docker Compose
```bash
cd docker
docker compose up -d
```
